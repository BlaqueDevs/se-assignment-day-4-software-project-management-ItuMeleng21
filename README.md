# SE_DAY4_Software-Project-Management
## 1. Why is timely delivery crucial in software project management, and how can project managers ensure that deadlines are met?
Timely deivery in software project is crucial as it ensures that project deadlines are met on time. Project managers ensure this is possible by applying the key components of project planning namely,scope,schedule,buget,risk management and tools and techniques. 

## 2. How does effective cost control contribute to the success of a software project? What strategies can be used to prevent budget overruns?
To prevent software project managers from overspend or underspend on resources. Strategies can be followed to enable this is by having a budget plan and sticking to it, monitoring use of resources and expenses.    

## 3. Compare and contrast Agile and Waterfall methodologies. What are the main advantages and disadvantages of each? 
Agile methodology is the flexible method in which new ideas can be added along the way.It's advantages is that it enables for new ideas to be put together,and disadvantages is it involves customers most of the time. Waterfall methodology is a sequantial method with sequancial phases. This method's advantage is that it is easy to manage.And it's disadvantage is since it's sequecial testing happen at far end in which if there is a mistake then you have to start from the beginning.

Agile is more beneficial in projects that are flexible like video games building there is a lot of playtesting involved in which the game will get enhanced. Waterfall is a sequencial phases an example will include building a skyscraper or a bridge you have to plan the project steps and obviously you have to begin with foundation when building.   

## 5. What are some methods for ensuring quality assurance throughout a software project? Why is it important to maintain high standards?
Methods of ensuring quality assurance include code reviews and walkthroughs. It is important to maintain high standards to prevent cost on post release bugs.

## 6. How does defining the project scope contribute to successful project planning? What is a Work Breakdown Structure (WBS), and why is it useful?
Defining project scope is important as it gives an overview of what the project is all about or which problem needs to be solved. WBS is the breakdown of the project into components. It is important as it break projects into manageable tasks amd assure resources are allocated effectively. 

## 7. What are the benefits of developing a detailed project schedule, and how can Gantt charts assist in this process?
Developing a project schedule ensure time management,resource allocation and keep team on track. Gantt chart visually represent timelines task dependencies, and milestones, making them excellent planning tools.
